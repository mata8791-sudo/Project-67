PROJECT 67 PHONE v1.0
1. Extract the ZIP.
2. Host the folder from any HTTPS/static web host, or open index.html for basic testing.
3. On Samsung Internet/Chrome, use the browser menu and choose Add to Home screen/Install app when available.
4. Data is stored locally in the browser. Use Data > Export Backup regularly.
5. This is a prototype. The next PC build can replace the local database with a shared server/database.
